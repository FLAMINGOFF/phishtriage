# data/private

Real email samples for evaluation (for example from
[phishing_pot](https://github.com/rf-peixoto/phishing_pot) or the SpamAssassin ham corpus)
go here. Everything in this directory except this file is git-ignored.

Handle real phishing only inside a disposable VM, never open attachments, and never commit
or share these files: they can contain live malware and personal data.
