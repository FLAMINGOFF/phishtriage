# Sample reports

Synthetic emails for trying the report mailbox: `python3 scripts/send_sample.py` sends each
one to `report-phishing@example.edu` as an attachment, the way an employee would report
it, and PhishTriage replies to the sender in Mailpit (http://localhost:8025). See
[docs/mailbox.md](../docs/mailbox.md).

| File | What it is | Expected reply |
| --- | --- | --- |
| `credential-phish.eml` | Look-alike domain, "IT Service Desk" display name, asks for the password, quoted-printable body | Malicious |
| `link-mismatch-html.eml` | Spoofs `example.edu` (DMARC fail); HTML link text differs from its target; login form | Malicious |
| `gbk-invoice-zh.eml` | Chinese password phish in GBK under a `gb2312` label, link to a bare IP address | Suspicious |
| `attachments-macro-lnk-rlo.eml` | Executable, macro document, `.lnk` shortcut, right-to-left override in a file name, encrypted ZIP | Malicious |
| `punycode-ip-shortener.eml` | "Payroll Office" from free webmail, punycode domain, IP host, URL shortener | Malicious |
| `forged-auth-results.eml` | Carries a forged "all pass" `Authentication-Results` header that must not help it | Suspicious |
| `benign-internal.eml` | Ordinary internal notice | No issues found |
| `benign-newsletter.eml` | Authenticated HTML newsletter | No issues found |

All of them are generated by `scripts/generate_emails.py` (copies of fixtures in
`tests/fixtures/emails/`; CI checks that they are up to date). They use only reserved
domains (`example.com`, `example.edu`, `.example`, `.test`) and documentation or private IP
ranges, and contain no real addresses, no real links and no working malware: the
"executables" are a few harmless bytes behind the right magic number, and the macro
document holds a VBA project skeleton without code.
